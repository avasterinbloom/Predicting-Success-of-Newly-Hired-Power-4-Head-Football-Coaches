# Coaching Hires Regression Project

## Project purpose

This repository analyses the association between pre-hire coach characteristics and the project-defined Coach Performance Index (CPI), stored as `sp_rel_team`. It separates a full confirmatory OLS model for H1-H4 from a BIC-selected model used for prediction. The report is in `reports/final_report.pdf`; editable source is `reports/final_report.tex`.

## Folder map

- `R/`: 16 main R scripts (setup, exploration, missingness, OLS, diagnostics, remedies, collinearity, model construction/selection, mixed models, simultaneous inference, logistic, resampling, survival, holdout, stretch checks).
- `lib/`: shared model definitions, data pipeline, supplemental inference, decision-rule, audit, and corrected LRT helpers.
- `data/raw/`: original 132 x 60 CSV and SHA-256 file.
- `data/processed/`: six RDS data/model objects generated by the pipeline.
- `figures/`: 19 figures used in the analysis and report.
- `tables/`: 55 archived numerical result, diagnostics, inclusion/exclusion and validation tables.
- `reports/`: final PDF/TeX report, original R Markdown and HTML (preserved unchanged), memos and provenance logs.

## Reproduce the analysis

Use R (the archived session records R 4.6.1) and install the packages loaded by `R/00_setup.R`: `tidyverse`, `MASS`, `car`, `lmtest`, `leaps`, `glmnet`, `nlme`, `survival`, `boot`, `bootstrap`, and `ResourceSelection`. Report rendering additionally requires `rmarkdown`, `knitr`, and `kableExtra`.

From this directory run:

```bash
bash run_analysis_only.sh
```

This runs the statistical scripts without rendering or overwriting `reports/final_report.html`. To execute the original complete runner, use `bash run_all.sh`; its final step renders the R Markdown and can overwrite the HTML file. Back it up first if you need to preserve that exact render.

To rebuild the final report PDF only:

```bash
cd reports
bash build_pdf.sh
```

The TeX report is self-contained and compiles with XeLaTeX. Run it twice to update the contents and references.

## Dataset provenance and checksum

The raw dataset is the team-compiled `data/raw/data.csv` (132 records, 60 variables). Coach-profile URLs are stored in its `Wikipedia` column. Historical SP+ input sources are not fully mapped in a separate source ledger; this limitation is documented in the report. Verify the supplied raw file with:

```bash
sha256sum -c data/raw/data.csv.sha256
```

Expected SHA-256: `059dc4c7186128d431ade38213f70e3bf044f3a18f99e466704cb12fe63a3d81`.

## Interpretation boundary

No H1-H4 hypothesis survives Holm correction. The full model performs worse than the null under 10-fold cross-validation. The BIC model has modest cross-validated fit and does not beat the simple mean baseline in the post hoc temporal holdout. The Coach Hire Score is exploratory, not a validated hiring instrument. The report also flags unresolved mixed-effects and holdout-output discrepancies; rerun and reconcile these before claiming a fresh end-to-end reproduction.
